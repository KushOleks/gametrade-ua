# GameTrade UA

Український маркетплейс ігрових цінностей на ASP.NET Core MVC (.NET 8).

## Запуск

```sh
dotnet run
```

Відкрийте адресу з термінала та перейдіть у «Каталог» (`/Products`).

## Лабораторні 1–2

- MVC, маршрутизація, MarketplaceInfoService через DI та RequestLoggingMiddleware.
- Product з DataAnnotations; серверна валідація через ModelState.
- IProductService / InMemoryProductService, зареєстрований як Singleton.
- Index, Details, Create, Edit і Delete; Razor Tag Helpers та model binding.
- POST-форми захищені antiforgery токенами; видалення потребує підтвердження.
- Сервіс синхронізує конкурентні запити та повертає копії даних.

Дані спільні для всіх відвідувачів одного процесу й скидаються після перезапуску.
Це демонстраційний етап: авторизацію, права власника оголошення, постійну БД,
платежі та угоди потрібно додати перед публічним використанням.

## HTTP-перевірка

Після запуску: `python3 tests/smoke.py http://localhost:ПОРТ`. Скрипт створює та видаляє тестове оголошення.

## Перевірка вручну

1. Відкрийте каталог та деталі початкових трьох оголошень.
2. Створіть товар із дробовою ціною; перевірте його в каталозі.
3. Надішліть порожню назву або нульову ціну: форма має показати помилки.
4. Відредагуйте товар і доступність; перевірте деталі.
5. Скасуйте видалення, потім підтвердьте його.
6. Перейдіть на `/Products/Details/999999`: очікується 404.
7. Перезапустіть сервер: відновляться початкові дані.
