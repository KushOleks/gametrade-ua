# GameTrade UA

Український маркетплейс ігрових цінностей на ASP.NET Core MVC (.NET 8).

## Запуск

```sh
dotnet run
```

Відкрийте адресу з термінала та перейдіть у «Каталог» (`/Products`).

## Лабораторні 1–2

- MVC, маршрутизація, MarketplaceInfoService через DI та RequestLoggingMiddleware.
- Product з DataAnnotations; серверна валідація через ModelState.
- IProductService / InMemoryProductService, зареєстрований як Singleton.
- Index, Details, Create, Edit і Delete; Razor Tag Helpers та model binding.
- POST-форми захищені antiforgery токенами; видалення потребує підтвердження.
- Сервіс синхронізує конкурентні запити та повертає копії даних.

Дані спільні для всіх відвідувачів одного процесу й скидаються після перезапуску.
Це демонстраційний етап: авторизацію, права власника оголошення, постійну БД,
платежі та угоди потрібно додати перед публічним використанням.

## HTTP-перевірка

Після запуску: `python3 tests/smoke.py http://localhost:ПОРТ`. Скрипт створює та видаляє тестове оголошення.

## Перевірка вручну

1. Відкрийте каталог та деталі початкових трьох оголошень.
2. Створіть товар із дробовою ціною; перевірте його в каталозі.
3. Надішліть порожню назву або нульову ціну: форма має показати помилки.
4. Відредагуйте товар і доступність; перевірте деталі.
5. Скасуйте видалення, потім підтвердьте його.
6. Перейдіть на `/Products/Details/999999`: очікується 404.
7. Перезапустіть сервер: відновляться початкові дані.

## Практична №3: маршрути, фільтри та демонстраційна адмінчастина

- Каталог: `/products`, `/products/index`, `/items`, `/items/index`.
- Деталі: `/products/1` та сумісна адреса `/products/details/1`.
- Створення: `/products/create` і `/products/new`; редагування та видалення: `/products/edit/1`, `/products/delete/1`.
- Додаткові маршрути використовують наявний контролер і Razor-представлення.
- GET-фільтри: `Search`, `Game`, `Category`, `MinPrice`, `MaxPrice`, `OnlyAvailable`.
  Наприклад: `/products?Search=Redline&MinPrice=100&MaxPrice=1000&OnlyAvailable=true`.
  Всі умови застосовуються разом, межі ціни включні. Неправильні числа та діапазони показують помилки без результатів.
- Відсутнє оголошення повертає оформлену сторінку з текстом `The product does not exist`, посиланням на каталог та HTTP-статусом 404. Представлення повертається без HTTP-редиректу, щоб зберегти статус 404.
- `/users/index` без доступу повертає 401 і форму. POST з полем `accessCode` у тілі, значенням `df2323eoT` та antiforgery токеном відкриває вигадані записи. Код у query string не приймається. Прямий POST без antiforgery токена повертає 400.
- Це навчальний механізм з умови, не авторизація для публічного маркетплейсу. Надалі замінити на облікові записи й ролі; зараз користувачі не пов’язані з власністю оголошень.
- HTTP-перевірка: `python3 tests/smoke.py http://127.0.0.1:5187` після запуску сервера на цьому порту. Скрипт перевіряє також CRUD із практичної №2.
